# Standout Skills

Design-taste skills for AI coding agents, from [Standout](https://standoutmcp.io) - the design engine that stops AI-built sites looking AI-generated.

## Install

```bash
npx skills add Blackbear6997/standout-skills
```

Works with Claude Code, Cursor, Codex, and any agent that reads skill files.

## Skills

- **standout-design-taste** - the anti-slop discipline: picks one real art direction from the free [DESIGN.md library](https://standoutmcp.io/directions), locks palette and type, and bans the recognizable AI tells (purple gradients, centered-everything heroes, three-card rows, fake proof, slop copy).

## The full engine

The skill is the free taste layer. The Standout MCP server hands your agent the working product: finished art-directed section code, interactive set pieces, a WebGL motion layer, cinematic showpiece skeletons, and a critic that renders your page and scores it.

One config entry, free trial key: **https://standoutmcp.io**
